Question 1

How to Attempt?

A tech company uses a custom numbering system that excludes any number containing the digit 7. You are given an integer K denoting the desired position in the filtered sequence, and your task is to find and return a string value representing the Kth valid number in the sequence of natural numbers that do not contain the digit 7.

Note: Assume 1-based indexing.

Input Specification:

input1 : An integer value K, representing the desired position in the sequence.

Output Specification:

Return a string value representing the Kth number in the sequence of natural numbers that do not contain the digit 7.

Example 1:

input1 : 7
Output : 8

Explanation: The filtered sequence begins 1, 2, 3, 4, 5, 6, 8, ... For K = 7, the 7th number is 8.

Example 2:

input1 : 17
Output : 19

Explanation: The filtered sequence continues 1, 2, 3, 4, 5, 6, 8, 9, 10, 11, 12, 13, 14, 15, 16, 18, 19, ... For K = 17, the 17th number is 19.
